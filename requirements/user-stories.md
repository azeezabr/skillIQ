# User Stories

## Role exploration
- As a job seeker, I want to click a job role tab so that I see skills specific to that role.
- As a user, I want the active tab to be visually distinct so that I know which role I'm viewing.

## Filtering
- As a user, I want to filter by location so that I see skills relevant to my job market.
- As a user, I want to filter by date range so that I can see recent vs. historical demand.
- As a user, I want to filter by industry so that I can focus on the sector I'm targeting.
- As a user, I want an Analyze button so that filters apply on demand, not on every change.

## Skills insight
- As a user, I want to see skills ranked by occurrence so that I know which ones appear most often.
- As a user, I want a visual bar for each skill so that I can compare them at a glance.
- As a user, I want a trend badge (Trending / Stable / Declining) so that I know if demand is growing.
- As a user, I want to toggle to a Trending sort so that I can prioritize fast-moving skills.

## Summary metrics
- As a user, I want to see total job postings for the current filter so that I know how large the sample is.
- As a user, I want to see open roles count so that I know the current hiring activity.
- As a user, I want to see median salary so that I can gauge compensation expectations.
